📊Finance Sales and Profit Analysis | Power BI

An interactive Finance Dashboard built using Power BI to analyze financial performance across sales, profit, gross sales, units sold, countries, products, and business segments. The dashboard provides clear insights into monthly trends and overall business performance through interactive visualizations and filters.

Key Features:
💰 Total Sales, Gross Sales, Profit, and Units Sold KPIs
📈 Monthly Sales trend analysis
🌍 Country-wise Profit analysis
📊 Segment-wise Profit comparison
🌎 Country-wise Sales distribution
🛍️ Product-wise Sales analysis
📅 Year-wise filtering
👥 Interactive business segment selection
🎯 Dynamic and interactive visualizations

Tools Used:
Power BI | Power Query | DAX | Data Modeling | Data Analysis | Data Visualization
